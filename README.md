# Global Deforestation Modeling Project
This project analyzes global deforestation trends using environmental, urbanization, and consumption-related predictors from a large open-source dataset. It was completed as part of a semester-long Statistics and Operations Research group project using R.

## Project Overview
The goal of this project was to explore factors associated with global tree deforestation and develop an interpretable statistical model. Our team used web scraping, data cleaning, exploratory analysis, regression modeling, and model selection to identify meaningful predictors and communicate findings clearly.
